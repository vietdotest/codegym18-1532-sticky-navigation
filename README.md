# Sticky Navigation

Thanh điều hướng sticky top:0 theo mẫu; bốn phần đủ dài để kiểm tra cuộn, menu co gọn ở màn hình nhỏ.

## Chạy
Mở index.html trong trình duyệt.

## Đề bài
https://internship.codegym.vn/learning/18/activity/1532

## Kiểm tra
375, 768, 1440 px không tràn ngang. Menu con ẩn mặc định, mở khi dùng Tab. Header/sticky giữ top=0 sau khi cuộn bằng liên kết nội trang.
